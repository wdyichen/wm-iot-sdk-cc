# 依赖包目录

构建 Docker 镜像前，请将以下文件放入本目录：

| 文件名 | 说明 |
|--------|------|
| `csky-elfabiv2-tools-x86_64-minilibc-20210423.tar.gz` | CSKY 交叉编译工具链 |
| `XuanTie-DebugServer-linux-x86_64-V5.18.1-20240513.sh.tar.gz` | XuanTie DebugServer（JTAG 调试） |
| `cmake-3.25.1-linux-x86_64.sh` | CMake 3.25.1 Linux 预编译安装包 |
| `ninja-linux.zip` | Ninja 预编译可执行文件 |
| `ccache-4.7.4-linux-x86_64.tar.xz` | Ccache 4.7.4 预编译包 |

> 工具链与 DebugServer 也可从 [玄铁资源中心](https://www.xrvm.cn/community/download) 或 [WinnerMicro 官方文档](https://doc.winnermicro.net/w800/zh_CN/latest/get_started/linux.html) 获取。
